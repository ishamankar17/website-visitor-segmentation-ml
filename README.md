# Website Visitor Segmentation

An end-to-end machine learning project that segments website visitors based on their browsing behaviour and purchasing patterns using K-Means clustering. The project includes data preprocessing, feature engineering, model evaluation, and an interactive Streamlit dashboard for exploring visitor segments.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering and scaling
- K-Means clustering and optimal cluster selection
- Visitor segment analysis and purchase rate evaluation
- Interactive Streamlit application for individual and batch predictions
- Automated testing and Docker support

## Tech Stack
- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn, K-Means, StandardScaler
- **Visualization:** Matplotlib, Seaborn
- **Web Application:** Streamlit
- **Testing:** Pytest
- **Deployment:** Docker, GitHub Actions

## Dataset
**UCI Online Shoppers Purchasing Intention Dataset** — contains 12,330 website sessions with visitor behaviour, browsing activity, and purchase-related information.
